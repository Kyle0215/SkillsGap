# Sample syllabi (fictional)

These three syllabi were written by Team ArgonUT only to demonstrate SkillsGap.
They are **fictional**. They are not real UNITEN courses and are not copied from any real syllabus.
The course codes (SAMPLE-DA101, SAMPLE-NS201, SAMPLE-PM301) are made up.

| File | Course | Suggested role |
|---|---|---|
| `intro_data_analytics.txt` | Introduction to Data Analytics | Data Analyst |
| `network_security_fundamentals.txt` | Network Security Fundamentals | Cybersecurity Analyst |
| `engineering_project_management.txt` | Engineering Project Management | Project Manager |

They are kept outside `data/` because `data/` holds the data team's read-only files (CC BY-SA 4.0).
Never put real syllabi in this folder or anywhere in the repo.
